# Автотесты для сервиса «Яндекс.Самокат» (Sprint_6)

Проект содержит автоматизированные тесты для учебного сервиса «Яндекс.Самокат».

## Реализованные проверки
1. **Выпадающий список в разделе «Вопросы о важном»**: проверка открытия соответствующего ответа для каждого вопроса (параметризация).
2. **Заказ самоката**: проверка позитивного сценария заказа с двумя разными наборами данных и двумя точками входа (кнопки «Заказать» вверху и внизу страницы).
3. **Редиректы по логотипам**:
   - Клик на логотип «Самокат» ведет на главную страницу «Самоката».
   - Клик на логотип «Яндекс» открывает в новом окне страницу Дзена.

## Используемые технологии
- Python 3
- Pytest
- Selenium WebDriver (GeckoDriver / Firefox)
- Page Object Model (POM)
- Allure Framework (отчёты)
